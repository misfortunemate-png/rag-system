## 2. 実施内容（W-1〜W-2）

### W-1: コンポーザーの空答リトライ（1回）

`src/agent.py` の `_run_composer()` および `make_composer_stream()` の `get_result()` に追加:

1. コンポーザー応答 `answer.strip()` が空の場合、同一入力で 1 回だけ再呼び出し
2. リトライ時のトークン数を初回と合算（P-9 準拠）
3. ログに `composer: empty answer — retrying once (composer_retry=True)` を WARNING 出力
4. debug dict に `"composer_retry": bool` フラグを追加
5. リトライ後も空の場合、ハードコード定型文を返す:

```
回答の生成に失敗しました。同じ質問をもう一度お試しください。
```

両パス（非ストリーミング `_run_composer` / ストリーミング `make_composer_stream.get_result()`）に実装。

### W-2: topk 既定値の変更

`src/config.py` の `AgentConfig.top_k: int` を `3` → `5` に変更。

根拠: ret は topk10 と同水準、空答の再現率が低い、コストが低い（$0.076 vs $0.088）。
