# 規程エージェント M3.1 作業指示書 — 回答メタデータの常時表示

作成日: 2026-08-07 ／ PM: クリーデ（Opus席）
前提: M3完了（三役構成・設定・デバッグ稼働）
性質: 小規模修正（簡略フロー適用）

## 背景

コスト・所要時間は「デバッグ情報」ではなく「回答の属性」である。
規程エージェントの価値はトレース＝検証可能性にあり、回答がいくらで・
何秒で作られたかは回答本体に添えるメタデータとする（発注者指示 2026-08-07）。

## 作業内容

1. 各回答の末尾に**メタデータフッター**を常時表示する:
   - 合計所要時間（秒）
   - 段別内訳: プランナー／実行ループ（回数含む）／コンポーザー それぞれの
     所要時間・トークン数
   - 概算コスト合計（円換算は不要、USDで可）
   - 使用モデル構成（三スロットの中身）
2. 表示は控えめな体裁（st.caption等）。回答本文の可読性を損なわない
3. 会話履歴の過去回答にも同フッターを保持する（session_stateに保存）
4. デバッグパネルからコスト・時間の集計表示は撤去し、生トレースJSON・
   invalid_citationログ・eval投入・設定リセットのみ残す

## 完了条件

- 全回答にフッターが付き、履歴でも保持される
- start.bat起動で動作確認・push・docs/reports/に報告
