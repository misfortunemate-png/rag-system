追加: requirements.txt に streamlit を追加すること。

## レイアウト（spec §7準拠）

左カラム＝チャット、右カラム＝根拠パネル。

### 左カラム（チャット）
- 質問入力欄（下部）
- 回答表示（Markdown対応）
- エージェント動作トレース：ツール呼び出しを逐次表示する。表示形式は「🔍 search_chunks: "分電盤 保護等級"」「📖 read_section: "第2編/第1章/第7節/1.7.2"」のように、ツール名と引数を簡潔に出す。回答生成中は「⏳ 回答を生成中...」等のインジケータ

### 右カラム（根拠パネル）
- 回答の出典となったチャンクの原文を表示
- hierarchy（階層パス）、pages、source_engineを添える
- 複数チャンクがある場合は縦に並べる

### 出典チップ
- 回答本文中の条番号（1.7.2等）をst.expander等で展開可能にする、またはクリックで右カラムの該当箇所にスクロールする。完全な実装が困難なら、右カラムに出典チャンクが並んでいるだけでも可（最低限）

## デザイン指針

- 青×白基調（Streamlitのデフォルトテーマで概ね実現できる）
- 装飾より「動きが見える」ことを優先
- レスポンシブ対応は不要（デスクトップ幅を前提）

## 技術指針

- Streamlitのst.chat_message、st.columns、st.sidebar等を活用
- エージェントのトレースはM1のagent.pyが返すトレースリストを使用
- ストリーミング表示はst.status、st.spinnerで十分。WebSocket等の実装は不要
- session_stateで会話履歴を管理

## テスト

| テスト | 方法 | 合格条件 |
|---|---|---|
| 基本動作 | M1 eval質問のうち3問をUIで実行 | 回答・トレース・根拠パネルが表示される |
| トレース表示 | 上記実行中の画面 | ツール呼び出しが逐次表示される |
| GIF撮影 | 1問の質問→回答を画面録画 | 30秒デモとして成立する動きがある |

## 禁止事項

- React等への置き換え（M2はStreamlit固定）
- M1のagent.pyの大規模リファクタ（インターフェース調整の軽微な変更のみ可）
- 認証・マルチユーザー機能
- ショウゴさんにPowerShellコマンドを叩かせること（R-015）

## 完了条件

- start.bat のダブルクリックで起動し、質問→トレース→回答→根拠パネルの一連が動作すること
- GIF撮影可能な状態（実際のGIF撮影は発注者が行う）
- push済み

## 起動手順

1. setup.bat をダブルクリック（初回のみ。venv作成＋依存インストール）
2. .env.example を .env にコピーし、APIキーを記入
3. start.bat をダブルクリック（.envから環境変数を読み込み、streamlit run app.py を実行）
