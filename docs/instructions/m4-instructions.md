# 規程エージェント M4 作業指示書 — アドバイザー・速度改善・モデル拡充

作成日: 2026-08-08 ／ PM: クリーデ（Opus席）
対応設計: docs/answer-quality-design.md §7（アドバイザー構想）
前提: M3.1完了（三役構成・設定・引用検証・回答メタデータフッター稼働）

## スコープ概要

1. モデルプリセットの拡充（chat-pwa準拠）
2. アドバイザー（第四の役）＋発動条件の設定化
3. 早期打ち切り（決定的ルール）
4. コンポーザー出力のストリーミング表示
5. search_chunksの並列発行

## 1. モデルプリセットの拡充

- 三役＋アドバイザーの計四スロットのプリセット一覧を、**chat-pwaと同じ
  ラインナップ**に揃える。フラン上の D:\AI\github\chat-pwa のモデル定義
  （生成パラメータ制御まわりのプリセット）を参照して同じ選択肢を移植する
- 自由入力欄は維持（プリセット外のモデルIDを直接指定可）
- provider=anthropic直接の場合のモデルID対応表も既存方式を維持

## 2. アドバイザー（第四の役）

行き詰まった探索を方向転換する役。詳細設計は answer-quality-design.md §7。
**本実装では選択肢(c)ユーザー問い返しは実装しない**（発注者裁定 2026-08-08）。

### 職務
質問＋プランナーの計画＋トレース要約＋既収集チャンク一覧を受け、次を裁定:
- **(a) 再計画**: 新しい検索方針・クエリ群を出して実行ループ続行
- **(b) 守備範囲外裁定**: 探索を打ち切りコンポーザーへ（第二段回答を指示）

### 設定（サイドバー・アドバイザー節を新設）
- モデルスロット（第四スロット・プリセット＋自由入力）
- **発動条件チェックボックス（複数選択可）**:
  - □ 常時 — 全質問で発動（プランナー直後に1回）
  - □ プランナー裁量 — プランナーが質問受領時の分類で「要アドバイザー」と
    判定した場合（プランナー出力に advisor_recommended: bool を追加）
  - □ 難航検知 — ループ数 > MAX_LOOPS/2 かつ 直近kループの新規チャンク獲得ゼロ
    （決定的コードで判定。k=2既定）
  - □ 未決着 — MAX_LOOPS到達時点で十分な根拠が集まっていない場合、
    コンポーザー呼び出しの直前に1回
- 既定値: 難航検知のみON
- **ガード: 発動は1質問につき最大1回**。複数条件を満たしても最初の1回のみ。
  発動有無・裁定内容はトレースと回答フッターに記録

## 3. 早期打ち切り（アドバイザーの下の安全網）

- 決定的ルール: 直近kループ連続で新規チャンク獲得ゼロなら実行ループを
  打ち切りコンポーザーへ（k=3既定・設定でスライダー化 2〜5）
- アドバイザー(a)再計画後も同ルールは生きる（再計画後の空振り継続で強制終了）
- 打ち切り発生はトレースに「⏹ 早期打ち切り」として明示

## 4. コンポーザー出力のストリーミング表示

- コンポーザーの回答本文をトークン単位で逐次表示（st.write_stream等）
- 引用宣言（cited_chunk_ids）の構造化出力と両立させること。実装方式はPG裁量
  （例: 本文ストリーム後にJSON部を非表示で受けてパースする二部形式等）。
  方式に迷いがあれば着工前にdocs/reports/で相談
- ストリーム中も右カラム根拠パネルは完了後更新で可

## 5. search_chunksの並列発行

- 実行ループが1ターンで複数のsearch_chunksを要求した場合、逐次でなく
  並列実行する（ThreadPoolExecutor等。Chroma問い合わせはローカルなので軽い）
- read_sectionは従来通りで可（並列化の効果が薄い）
- 同一クエリの重複発行は検知してキャッシュを返す

## テスト

| テスト | 方法 | 合格条件 |
|---|---|---|
| 後方互換 | アドバイザー全条件OFF＋既定設定でeval実行 | M3と同等の結果 |
| アドバイザー(b) | 難航検知ONでR1・R2（questions-refusal.jsonl）を実行 | 発動が記録され、幻覚なしの第二段/前提訂正回答。M3比で所要時間短縮 |
| アドバイザー(a) | 常時ONでeval Q4またはQ8を実行 | 再計画がトレースに記録される |
| 早期打ち切り | 打ち切りが起きる質問で確認 | ⏹表示・コンポーザーが正常に回答 |
| ストリーミング | 任意の質問 | 回答本文が逐次表示され、引用検証も機能 |
| 並列発行 | プランナーの複数クエリ質問 | フッターの所要時間がM3比で短縮 |
