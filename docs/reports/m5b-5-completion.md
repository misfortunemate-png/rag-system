## 2. 実施内容（W-1〜W-4）

### W-1: domain自動絞り込みの既定OFF
`_build_planner_system()` から `relevant_domains` 出力指示と `domain_section` を削除。  
呼び出し元の R-10 ブロック（agent.py 740行付近）を無効化し `effective_domains = user_domains` に置換。  
ログに `R-10 disabled (M5b-5): effective_domains=...` を出力。

### W-2: ツールレベルのdomain引数除去
`TOOLS` リストの `search_chunks` パラメータから `domain` プロパティを削除。  
Python シグネチャ（`domain: str | None = None`）は後方互換のため残置。

### W-3: ゼロ件セーフティ（filter_fallback）
`search_chunks()` 内: フィルタ付きで hits=0 の場合、同一クエリでフィルタなし再検索を1回自動実行。  
フォールバックチャンクに `"filter_fallback": True` フラグを付与。ログに `filter_fallback: domains=... -> unfiltered` を出力。

### W-4: トレース記録の拡充
`run_crossdomain_eval.py` に `_slim_trace()` 関数を追加。  
thinking・チャンク本文を除去し、各ループの `name`, `input`（query/domain/doc_ids）, `hits` 件数を記録。  
結果JSONの `"trace"` フィールドに格納。

# RC造既存梁への冷温水管貫通孔新設に関する規定

## 1. 所蔵から言えること

### (1) 貫通孔径の制限（構造上の最大径）

**RC造の場合（既存建物の構造種別に応じて適用）**

建築構造設計基準の資料 第6章 鉄筋コンクリート造 6.2.2 梁貫通孔（kouzou-sekkei-shiryou-r3-0011）では、RC造梁の貫通孔径について次のように規定しています：

> **孔径は梁せいの1/3以下**で、貫通孔の中心間隔は両孔径の平均の３倍以上とする（貫通孔が円形でない場合は、外接円とする。）。

梁せい600mmの場合、**最大許容孔径 = 600 ÷ 3 = 200mm** となります。

**重要な判断点**：呼び径200の冷温水管に保温施工を行う場合、配管外径（呼び径200：JIS規格上の外径約216mm）に保温厚さ（40mm、kikai-shiyousho-r7-0194-1より）を加えた寸法が実質必要径となります。保温を含めた外径は約 **296mm** となり、RC造の最大許容孔径200mmを**超過**します。

SRC造では「孔径は梁せいの1/3以下**かつ鉄骨せいの1/2以下**」、鉄骨造では「孔径は梁せいの**1/2以下**」（kouzou-sekkei-shiryou-r3-0015, 0020）。

### (2) 貫通孔位置の制限

RC造（kouzou-sekkei-shiryou-r3-0011）：柱面から **1.5D（=900mm）** 以内には設置不可（最小1.0D）。梁下端より **D/3（=200mm）** の範囲内不可。

### (3) 補強の要否

有孔梁のせん断強度が無開口のせん断強度以上になるよう補強設計が必要。既製品使用時は第三者機関による評定・技術証明を要する。  
保温込み外径（約296mm）がRC造の最大許容孔径200mmを超えるため、構造設計者による**個別の構造検討と補強設計が必須**。

### (4) スリーブと配管・保温の施工

スリーブ径：保温を含む外径より **40mm程度大きなもの**（kikai-shiyousho-r7-0137）。約296+40=**336mm**程度必要。  
スリーブ材料：梁部分は鋼管製または亜鉛鉄板製（紙チューブ不可）。  
保温厚さ：冷温水管（Ⅲ種）呼び径200 = **40mm**（kikai-shiyousho-r7-0194-1）。  
防火区画貫通：隙間をモルタルまたはロックウール保温材で充填（kikai-shiyousho-r7-0183）。貫通部保温はロックウール保温材（kikai-shiyousho-r7-0192）。

## 2. 所蔵にないこと

- 既存RC造梁の開口補強の具体的な設計計算方法（RC規準等を参照）
- 既存建物の耐震診断上の開口評価
- 防火区画以外の構造耐力上の開口制限に関する具体的条文
- 改修工事における既存躯体の劣化調査方法の詳細

## 3. 推論で補えること

呼び径200の冷温水管を保温施工して梁せい600mmのRC造梁に貫通する場合、標準仕様書の範囲内での施工は困難（保温含む貫通必要径≒296mm が RC造最大許容孔径200mmを超える）。構造設計者による個別構造検討が必要。代替案：配管の系統分割による小径化、または配管経路の見直しも選択肢。

## 既存トイレの車椅子使用者対応多機能トイレへの改装について

### 1. 所蔵から言えること

#### (1) 便所の基本構造について（建築基準法・施行令）

建築基準法第31条（law-91a-53）、建築基準法施行令第28条（law-91b-48）。

ただし、**多機能トイレの具体的な寸法・設備基準そのものは、所蔵の建築基準法・施行令では直接規定されていません**。高齢者、障害者等の移動等の円滑化の促進に関する法律（バリアフリー法）とその告示が主要根拠。

#### (2) 関連する仕様書・設計基準からの指摘事項

- 建築設備計画基準（令和6年版）（setsubi-keikaku-kijun-r6-0033）：「高齢者、障害者等の移動等の円滑化の促進に関する法律等の関係法令の定めるところによる」
- 便房の操作部配置：JIS S 0026 による（kikai-shiyousho-r7-0479）
- 車椅子使用者用便房出入口の自動ドア：適用戸標準質量100kg以下、閉じ力130N以下、手動操作力40N以下（kenchiku-shiyousho-r7-0577-1、kaishu-kenchiku-r7-0215-1）
- 操作スイッチ：床面から中心まで1,000mm程度（kenchiku-shiyousho-r7-0578-1）

#### (3) スロープ通路（傾斜路）について

建築基準法施行令第26条（law-91b-46）：勾配は**8分の1（約7.1度）を超えないこと**。ご質問の勾配3度（約1/19）はこの基準を満たします。ただし、バリアフリー法の移動等円滑化基準では勾配1/12以下、幅120cm以上等の要件が別途あります。

### 2. 所蔵にないこと

- 車椅子使用者対応便所の具体的な寸法基準（便房内法、手すり位置・高さ、ドア有効幅等）→ バリアフリー法告示、JIS S 0026を参照
- スロープの幅・手すり等の詳細基準 → バリアフリー法の移動等円滑化経路関係基準を参照
- タイル内装の改修要否の具体的判断基準 → 防滑性能値等のメーカー技術資料を確認

### 3. 推論で補えること

1. **1500mm×1500mmの便房**：車椅子転回直径1500mmを確保する観点から、壁芯または仕上げ面で1600mm×1600mm以上が一般的。手すり・壁仕上げで実効寸法が減少するため拡張が必要な可能性が高い。
2. **幅800mmのスロープ**：建築基準法施行令第26条の傾斜路規定は満たすが、車椅子通行の一般的基準は幅1200mm以上。**通路幅の拡幅が必要**と考えられる。
3. **勾配3度（約1/19）**：バリアフリー法移動等円滑化基準の1/12以下を満たす。ただし**両側への手すり設置**が求められる場合がある。
4. **ドアの改修**：有効幅800mm以上（移動等円滑化基準では80cm以上）のドアが必要。自動ドア化または引き戸化の検討が必要。
5. **床タイル**：滑り抵抗値（すべり抵抗値0.4以上）の確認が必要。不十分な場合は防滑処理または張り替え。
6. **便器・衛生器具**：温水洗浄便座（kikai-shiyousho-r7-0409）、JIS S 0026 に基づく操作部配置（kikai-shiyousho-r7-0479）が必要。

**最低限の改装項目（推論）：**  
①便房寸法の拡張（車椅子転回スペース確保）、②スロープ通路の拡幅（1200mm以上）と手すり設置、③出入口の改修（有効幅確保・自動ドア化）、④便器・衛生器具の交換、⑤操作部の配置見直し、⑥床・壁仕上げの確認と改修
