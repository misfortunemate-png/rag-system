# 規程エージェント M4.5 作業指示書 — 文書投入基盤（受信箱・ツリー選択）

作成日: 2026-08-08 ／ PM: クリーデ（Opus席）
前提: M4完了。M5（マルチ文書化）の前段として文書の受け皿を整備する
対応ロードマップ: docs/roadmap-v1.md M5の前提工事

## スコープ概要

1. 受信箱intake（フォルダ投入＋bat一発でingest）
2. フォルダツリー＝分類（domain/タグの自動付与）
3. UI: 文書ツリー選択＋タグ絞り込み（検索スコープのフィルタ）
4. チャンク方式のプロファイル化（条番号型／汎用型）

## 1. 受信箱intake

- `data/inbox/` を新設。発注者はここにPDFを置き `intake.bat` をダブルクリック
  するだけ（R-015。bat はASCII・CRLF）
- intake処理（scripts/intake.py 等）:
  1. inbox配下を再帰走査し、PDFを検出
  2. SHA-256を計算し documents.yaml と照合
     - 同一ハッシュ既登録 → スキップ（ログに「既登録」と出力）
     - 同名・別ハッシュ → **上書きせず警告して当該ファイルを停止**（他は続行）。
       再投入は発注者が旧登録の扱いを判断してから
  3. 新規 → documents.yaml に自動登録（id・title=ファイル名由来・
     domain/タグ=フォルダパス由来・sha256・profile・ingest日時・status）
  4. 抽出→チャンク→埋め込みを実行し、Chromaへ追加
     （チャンクのメタデータに doc_id / domain / tags を必ず付与）
  5. 処理済みPDFを data/raw/ 配下へ移動（フォルダ構造を保持）
- 冪等（N-10）: intake.bat を何度叩いても壊れない。中断後の再実行で続きから
- 既存の公共建築工事標準仕様書は再ingest不要。documents.yamlに現行情報を
  遡及登録するマイグレーションのみ行う（チャンク再生成しない）

## 2. フォルダツリー＝分類

- `inbox/<第1階層>/.../<ファイル>.pdf` の第1階層を domain、第2階層以降を
  タグ列として登録（例: inbox/電気/内線規程.pdf → domain=電気）
- inbox直下に直接置かれた場合は domain=未分類
- documents.yaml の手動編集も引き続き有効（intakeは手動編集値を尊重し、
  自動値で上書きしない）

## 3. UI: 文書スコープ選択

- サイドバーに「文書」節を新設:
  - フォルダ階層準拠のツリー表示＋文書ごとのチェックボックス
  - タグによる絞り込み（チェックボックス群で可）
  - 全選択／全解除
- チェックされた文書のみ検索対象。実装は search_chunks の Chroma メタデータ
  フィルタ（doc_id in [...]）。read_section も同スコープを尊重
- 選択状態は settings.json に保存・復元
- プランナーへの入力に「現在スコープ内の文書一覧（title・domain・タグ）」を
  documents.yaml から動的生成して渡す。文書ごとの解釈指示は書かない（事実の
  提示のみ。roadmap-v1「プロンプトは彫り込まない」に従う）
- 回答メタデータフッターに検索スコープ（対象文書数）を追記

## 4. チャンク方式プロファイル

- documents.yaml に profile 欄: `jouban`（条番号型・現行チャンカー）／
  `generic`（汎用型・新規実装: 見出し・ページベースの単純分割）
- intakeの自動判定: 抽出テキスト冒頭N ページに条番号パターンが規定密度以上
  あれば jouban、なければ generic（判定は決定的コード・閾値はコード内定数で可）
- 自動判定は仮置き。発注者/PMが documents.yaml で明示指定すれば優先
- generic は最小実装で可（品質の追い込みはM5の検証で行う）

## テスト

| テスト | 方法 | 合格条件 |
|---|---|---|
| 新規投入 | 任意のPDF1冊をinbox/テスト/に置きintake.bat | 登録・チャンク・移動が完走しUIツリーに現れる |
| 冪等 | 直後にもう一度intake.bat | 全スキップ・エラーなし |
| 衝突 | 同名別内容PDFを置きintake.bat | 警告して当該のみ停止・他は正常 |
| スコープ | UIで既存仕様書のみ選択→R1質問 | M4と同等の回答（回帰） |
| 除外 | UIで全文書解除→任意質問 | 検索0件を明示した回答（エラーで落ちない） |
| 遡及登録 | documents.yaml確認 | 既存仕様書がdomain付きで登録済み・再ingestされていない |
